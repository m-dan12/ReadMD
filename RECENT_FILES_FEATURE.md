# Функция "Недавние файлы"

## Описание
На стартовой странице приложения ReadMD теперь отображаются карточки с последними открытыми файлами (до 6 файлов). Каждая карточка показывает название файла и превью первых строк текста.

## Реализация

### Новые компоненты

1. **RecentFile.cs** - модель для хранения информации о недавнем файле
   - `FilePath` - полный путь к файлу
   - `FileName` - имя файла
   - `PreviewText` - превью текста (до 150 символов)
   - `LastOpenedAt` - время последнего открытия

2. **RecentFilesService.cs** - сервис управления историей
   - Хранит до 10 недавних файлов
   - Автоматически фильтрует несуществующие файлы при загрузке
   - Генерирует превью текста (без markdown заголовков)
   - Сохраняет в `%AppData%/ReadMD/recent_files.json`

3. **StartView.axaml** - обновленный UI стартовой страницы
   - Карточки в 2 колонки (WrapPanel)
   - Анимация hover с подъемом карточки
   - Иконка документа на каждой карточке
   - Адаптивная верстка

### Дизайн

**Цветовая схема:**
- Фон карточек: `SystemControlBackgroundAltHighBrush`
- Граница: `SystemControlForegroundBaseLowBrush` (1px)
- Заголовок: `SystemControlForegroundBaseHighBrush`, 14px, SemiBold
- Превью: `SystemControlForegroundBaseMediumBrush`, 12px
- Hover: подсветка фона + тень + translateY(-2px)

**Особенности:**
- Радиус скругления: 8px
- Минимальная высота: 100px
- Ширина карточки: 382px
- Отступ между карточками: 12px
- Плавные transitions (150ms)

### Интеграция

- `DocumentService` автоматически добавляет файл в историю при `LoadAsync()`
- `StartViewModel` загружает историю при старте
- Клик по карточке открывает файл через `OpenRecentFileCommand`

### Локализация

**Русский (ru.json):**
- `RecentFiles`: "Недавние файлы"
- `NoRecentFiles`: "Нет недавно открытых файлов"

**English (en.json):**
- `RecentFiles`: "Recent files"
- `NoRecentFiles`: "No recent files"

## Использование

1. Откройте любой .md файл через "Открыть файл"
2. Закройте файл или сверните приложение в трей
3. Вернитесь на стартовую страницу — файл появится в истории
4. Кликните по карточке для быстрого открытия
