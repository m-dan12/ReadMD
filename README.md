# 📖 ReadMD

Легкий и быстрый просмотрщик Markdown-файлов для Windows. Просто установите как приложение по умолчанию для `.md` файлов и читайте документы с удобством.

## 🎯 Основные возможности

- **🚀 Быстрое открытие** — минимальные затраты ресурсов, мгновенный запуск
- **📝 Редактирование** — режим редактирования для быстрых правок
- **🎨 Настройка типографики** — выбор шрифта, размер текста, высота строк, ширина строк
- **🌓 Темы оформления** — поддержка светлой и темной темы
- **🌍 Локализация** — интерфейс на русском и английском языках
- **💾 Автосохранение** — автоматическое сохранение изменений
- **📐 Удобное чтение** — оптимальная ширина строк для комфортного восприятия текста
- **🎯 Синтаксическое подсвечивание** — правильное отображение кода в блоках

## 📦 Требования

- **ОС:** Windows 10 / 11
- **.NET Runtime:** .NET 10.0 и выше

## 🚀 Установка и использование

### Запуск приложения

1. Загрузите последний релиз
2. Распакуйте архив
3. Запустите `ReadMD.exe`

### Установка как приложение по умолчанию

1. Откройте **Параметры** → **Приложения** → **Приложения и компоненты**
2. Нажмите на **Выбор приложений по умолчанию для типов файлов**
3. Найдите расширение `.md` и выберите **ReadMD**

Теперь все Markdown-файлы будут открываться в ReadMD при двойном щелчке.

## 🎮 Функциональность

### Просмотр документов
- Откройте любой `.md` файл через приложение или установите как приложение по умолчанию
- Удобный интерфейс с синтаксическим подсвечиванием кода
- Автоматическая прокрутка и масштабирование

### Режим редактирования
- Переключайтесь между режимом чтения и редактирования
- Автосохранение изменений каждые 2 секунды
- Живой просмотр (preview) при редактировании

### Настройки отображения
- **Шрифт** — выбор из доступных шрифтов (по умолчанию Lora)
- **Размер текста** — регулировка размера основного текста
- **Высота строк** — настройка интерлиньяжа для удобства чтения
- **Ширина контента** — выбор комфортной ширины текста (оптимально 700-850px)

### Язык интерфейса
- Автоматический выбор языка в зависимости от системных параметров
- Поддержка русского и английского языков
- Возможность переключения языка в приложении

## 🏗️ Техническая информация

### Стек технологий
- **Фреймворк:** [Avalonia](https://github.com/AvaloniaUI/Avalonia) 12.0.3
- **Язык:** C# 13
- **.NET:** .NET 10.0
- **Паттерн:** MVVM (Community Toolkit)
- **Markdown рендеринг:** [MarkView.Avalonia](https://github.com/NuGet/MarkView.Avalonia)
- **Иконки:** [FluentIcons](https://github.com/microsoft/fluentui-system-icons)

### Структура проекта

```
ReadMD/
├── Views/              # XAML представления (UI)
├── ViewModels/         # Логика представления (MVVM)
├── Services/           # Сервисы бизнес-логики
│   ├── LocalizationService.cs     # Локализация
│   ├── ThemeService.cs            # Темы оформления
│   ├── MarkdownDocumentService.cs # Работа с документами
│   ├── ReadingSettingsService.cs  # Сохранение параметров
│   └── ...
├── Models/             # Модели данных
├── Converters/         # XAML конвертеры
├── Assets/             # Ресурсы (шрифты, иконки, локализация)
└── DI/                 # Настройка зависимостей
```
